# Issue tracker

ModelSwitch has no issue tracker. Specs live in the repository:

- **Work items**: the phase and task lines of [docs/roadmap.md](../roadmap.md). A review's spec is the roadmap section as it stood at the review's fixed point (`git show <fixed-point>:docs/roadmap.md`), not as the diff left it.
- **Detailed requirements**: the PRD sections and design docs a task cites (FR/NFR/DoD ids in [PRD.md](../../PRD.md); design docs indexed in [README.md](../../README.md)). Commit messages carry the same ids in `[…]`, which is how a commit maps back to its requirement.
- **Review standards**: [docs/conventions.md](../conventions.md), "Review checklist".
